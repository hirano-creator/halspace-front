発注者・モデラー・社内の全員が見られるお知らせです。新しいお知らせは左メニューの「お知らせ」と右上のベルの両方に赤丸で件数が出ます。開くと既読になり、赤丸が減ります（既読は人ごと）。
本文に加えて画像（押すと拡大）と資料（PDF・Excel・Word・PowerPoint・3D データなど。動画は不可）を付けられます。資料はその場でプレビューでき、ダウンロードもできます。

通知の印

左メニュー「お知らせ」に件数の赤丸（チャットと同じ形）。全画面の右上にベル＋件数。スマホはメニューボタンにも赤丸。

画像

1枚目は本文の上に大きく、2枚目以降は並べて表示。押すと全画面で拡大し、左右で切り替え。一覧のサムネイルにも1枚目を使用。

資料

PDF・Office・STL などは SOLID の既存プレビューで開く。「まとめてダウンロード」あり。動画は載せない（選ぶと受け付けない）。

書く人

社内管理者だけ（ボタンも API も）。画像・資料はドラッグで追加。「重要」「ピン留め」を選べる。

既読の人数

社内管理者にだけ表示。押すと「読んだ人／まだの人」を会社ごとに確認できる。発注者・モデラーには出さない。
PC：お知らせページ — 一覧を押すと右に本文・画像・資料。画像や資料を押すとプレビュー。右上のベルで小窓。
