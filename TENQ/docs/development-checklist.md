# TENQ 開発チェックリスト

段階ごとの完了条件と、毎回のコミット・デプロイ前の確認項目。

## 毎回のコミット前

- [ ] 変更したのは TENQ 配下（または承認済みの他ファイル）だけか。`git add` はファイル・フォルダ指定（`git add -A` 禁止）
- [ ] 秘密情報・`.dev.vars`・DB エクスポート `.sql` が含まれていない
- [ ] 新しい依存パッケージを追加した場合、理由・サイズ・代替案をコミットメッセージに書いた
- [ ] SQL は prepared statement＋bind、会社・工場スコープを通している
- [ ] 権限判定は API 側にある（画面だけで隠していない）
- [ ] 記録系のデータを上書き・物理削除していない
- [ ] 監査ログが必要な操作で記録している
- [ ] `npm run lint`・`npm run typecheck`・`npm test` が通る
- [ ] スキーマ変更はマイグレーションファイルで行った（適用済みファイルは書き換えていない）

[deployment.md §3](deployment.md) の全項目＋オーナーの承認。
