# TENQ テスト計画

- 版: 0.1（第1段階・ドラフト）／作成日: 2026-10-22
- テストは**ダミーデータのみ**で行う。本番データ・本番環境を使わない

## 1. テストの種類と道具

| 種類 | 道具 | 対象 | 実行タイミング |
| --- | --- | --- | --- |
| 単体 | Vitest | 権限判定、状態遷移、期間計算、CSV エスケープ、入力検証 | コミットごと |
| API 結合 | Vitest + `@cloudflare/vitest-pool-workers`（ローカル D1 / R2） | 各エンドポイント、スコープ、トリガー、冪等性 | コミットごと |
| E2E | Playwright（Chromium + iPhone / Android 相当の画面サイズ） | 画面の主要な流れ | 段階の完了時・デプロイ前 |
| 実機 | iPhone（Safari）・Android（Chrome）・PC | QR 読み取り、カメラ、写真、印刷 | 段階の完了時 |
| 容量・負荷 | `npm run check:size`、簡易負荷スクリプト | バンドルサイズ、CPU 時間、D1 クエリ数 | デプロイ前 |

halspace-api の `/auth/me` は API 結合テストではスタブにする（トークン → 利用者の対応表）。E2E は既存アプリと同じく `mock-token...` を使い、API をスタブ化する方式と、ローカル halspace-api に繋ぐ方式の両方を用意する。

## 2. ダミーデータ

`api/test/fixtures/`（第2段階で作成）:

- 会社 2 社（越境テスト用）、各社 2 工場
- 各ロールの利用者（worker ×2、equipment_staff、factory_manager、system_admin、ロール未設定、利用停止中）
- 設備 30 台（稼働・停止・廃止を含む）、点検基準 3 種（うち 1 種は版 2 まである）
- 点検記録 60 日分、異常報告 各状態 1 件以上

## 3. テスト観点

| # | 観点 | 主な確認内容 | 段階 |
| --- | --- | --- | --- |
| T-01 | ログイン | 正しい資格情報・2段階認証で入れる／`tenq` 未付与は 403／利用停止は 403／ロール未設定は案内表示／トークン期限切れで再ログイン | 3 |
| T-02 | 権限 | requirements §3-2 の全マスを API で許可・拒否の両方確認 | 3〜6 |
| T-03 | 越境 | 他社・他工場の設備 ID・点検 ID・写真 ID を指定しても 404 | 3〜6 |
| T-04 | QR | 正しいトークンで正しい設備／再発行後の旧トークンは「再発行済み」／存在しないトークン／未ログインで読む → ログイン後に元の設備へ戻る | 3 |
| T-05 | 必須項目 | 必須未選択では画面で完了不可、API に直接送っても 422／対象外が許可されていない項目で na を送ると 422 | 4 |
| T-06 | 保存 | 判定・コメント・点検者・日時・基準の版が保存される／異常項目と異常報告の関連 | 4 |
| T-07 | 二重登録 | 同じ設備・同じ日に 2 件目が作れない（DB の一意制約）／完了の連打・再送で 1 件／別の人が点検中のときの表示と引き継ぎ | 4 |
| T-08 | 期間計算 | 日付の切り替わり（日本時間 0 時前後）、週・月、稼働曜日外、停止中設備が未点検に数えられない | 4 |
| T-09 | 異常の追跡 | reported → closed の正常系／不正な遷移の拒否／再確認者 = 是正実施者は拒否／差し戻し／全遷移が履歴に残る／危険度「高」の案内表示 | 5 |
| T-10 | 履歴 | 点検記録の訂正で元の記録が残る・理由必須／基準変更で版が増え過去の点検は旧版で表示／監査ログの UPDATE・DELETE がトリガーで拒否される | 4〜6 |
| T-11 | CSV・印刷 | Excel で文字化けしない（BOM）／`=1+1` 等のセルが数式にならない／件数上限／出力が監査ログに残る／A4 帳票・QR ラベルの印刷プレビュー | 6 |
| T-12 | 写真 | 10 MB 超は 413／偽装拡張子・SVG・PDF は拒否／枚数上限／他人の写真 ID を直接開けない／iPhone の HEIC が JPEG で保存される | 5 |
| T-13 | 画面 | スマホ（幅 375px）とPC（1280px）で主要画面が崩れない／入力欄 16px 以上でズームしない／点検が 3 手順で終わる | 3〜7 |
| T-14 | DB 整合性 | 外部キー違反が弾かれる／楽観ロックの 409／トランザクション（batch）の途中失敗で中途半端な記録が残らない | 2〜6 |
| T-15 | バックアップ・復元 | エクスポートを開発環境の新しい D1 に読み込み、件数と内容が一致する／Time Travel の手順を開発環境で実施 | 7 |
| T-16 | 容量・負荷 | Worker 非圧縮 1 MiB 以内／主要 API の CPU 時間（`wrangler tail` で確認）が無料枠 10ms に収まるか／1 リクエストの D1 クエリ数 50 以下／100 台・60 日分で一覧・ダッシュボードが 500ms 以内 | 7 |
| T-18 | 端末のログイン記憶 | 記憶ありで QR を読むとログインなしで点検表が開く／30 日で期限切れ／利用停止・端末取り消し後は即 401／PC では既定 OFF／トークンが D1 に平文で残らない | 3 |
| T-19 | エリア別カード一覧 | 6 つの状態が正しく判定され色・アイコン・文字が出る／点検完了で 30 秒以内に色が変わる／未配置の設備が「未配置」枠に出る／配置の編集・保存・同時編集の 409／他工場の配置が見えない | 6 |
| T-17 | セキュリティヘッダー | CSP・nosniff・frame 拒否・CORS の許可オリジン以外の拒否 | 7 |
