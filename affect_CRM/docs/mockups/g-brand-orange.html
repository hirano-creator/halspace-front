ロゴに合わせた配色の考え方
・ロゴが「黒＋オレンジのグラデーション」の 2 色構成なので、UI も無彩色＋オレンジ 1 色に絞った。案D の「アクセントは 1 色だけ」という方針とそのまま噛み合う
・グレーは青みを入れず中性グレーにしている。ロゴの黒とオレンジは暖色寄りなので、青みグレーだと色が濁って見えるため
・グラデーション（#e8402a → #f7941e）はロゴのマークから採り、保存ボタン・＋ボタン・アバター・今日の来店の上端ラインの 4 箇所だけに使用。多用するとロゴが埋もれる

ステータス表現の工夫
オレンジは「注意・警告」にも見える色なので、色数を増やさずに 塗り／輪郭／無彩色で 3 段階を作った。
・確定・購入 → オレンジの塗りドット　・仮予約 → オレンジの輪郭ドット　・未購入・キャンセル → グレードット

注意
サイドバーのロゴは、いただいた画像を見て CSS と SVG で近似再現したものです。実装時は本物のロゴデータ（SVG または PNG）に差し替えます。マークの角度・太さ・文字の字形は原本と細部が異なります。
